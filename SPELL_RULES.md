# Правила написания заклинаний Arcane 2D

Это полная памятка по языку заклинаний текущей сборки. Код заклинания —
**Python-подобный сценарий одного каста**, а не обычная программа на Python.
Сервер разбирает его собственным AST-интерпретатором и выполняет в песочнице.

## Коротко

- В гримуаре **3 руны** (слота), но боевых рун в API гораздо больше.
- Один каст — один запуск кода. Автоматического повторения и фонового выполнения нет.
- За каст можно сделать не больше **7 действий** и потратить не больше **100 маны**.
- Между кастами действует перезарядка **0,72 с**, мана восстанавливается сама.
- `Shift` — бесплатный перекат с кулдауном. Это отдельное движение, а не руна и не часть кода.
- Импорты, классы, `try/except`, файлы, сеть и `sleep` недоступны.
- Ошибка останавливает заклинание с этой строки; уже потраченная мана не возвращается.
- `aim()` — ручной прицел по курсору. Автонаводки нет: каждую атаку нужно направлять самостоятельно.

---

## 1. Как устроен каст

1. Ты пишешь код в одном из трёх слотов гримуара.
2. Код сохраняется в `localStorage` браузера. На сервер он уходит только при касте.
3. В момент каста сервер создаёт read-only представление состояния арены.
4. Код выполняется синхронно: условия, переменные и вычисления не занимают игрового времени.
5. Каждый вызов боевой руны тратит ману и одно действие.
6. После выполнения кода начинают работать снаряды, щиты, замедления, мины и таймеры.
7. Следующий каст возможен только после перезарядки гримуара.

Внутри кода **нельзя ждать**: нет `sleep()`, таймеров и доступа к времени.
`while` подходит только для вычислений; время в нём не идёт. Отложенный эффект
есть только у игровых механик вроде E.M.P., метеорита и ядовитого облака.

### Управление кастом

| Действие | Клавиши |
| --- | --- |
| Выбрать и сразу скастовать руну | `1`, `2`, `3` |
| Скастовать активную руну | ЛКМ по арене, `Space`, `Ctrl+Enter` |
| Перекат | `Shift` |
| Открыть/закрыть гримуар | кнопка `◈` |
| Сохранить гримуар | `Ctrl+S` (также автосохранение) |

Имя руны — до 28 символов, код — до 12 000 символов.

Перекат не запускает заклинание: он не тратит ману, не занимает действие и не
сбрасывает перезарядку гримуара. Направление берётся из текущего движения; если
маг стоит на месте — из прицела. На сервере перекат мгновенный, но клиент рисует
короткое вращение и след.

## 2. Язык заклинаний

### 2.1. Что поддерживается

- Числа: целые и с плавающей точкой.
- Строки, `True`, `False`, `None`.
- Списки, кортежи, словари.
- Арифметика: `+`, `-`, `*`, `/`, `//`, `%`, `**`.
- Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`.
- Логические операции: `and`, `or`, `not`.
- Тернарное выражение: `a if condition else b`.
- `if` / `elif` / `else`.
- `for`, `while`, `break`, `continue`, `pass`.
- `def` и `return`; функции существуют только внутри текущего каста.
- Присваивание и распаковка: `x, y = y, x`.
- Индексы и срезы: `items[0]`, `items[1:3]`.
- Простые f-строки: `f"HP: {me().hp}"`.
- Комментарии через `#`.
- Отступы обязательны, как в Python.

Элементы своих списков и словарей менять можно:

```python
items = [1, 2, 3]
items[0] = 10
```

А поля игровых объектов — нельзя. Объекты `me()` и `cursor()` доступны только для чтения.

### 2.2. Встроенные функции

| Функция | Назначение |
| --- | --- |
| `len(value)` | Длина строки, списка, кортежа или словаря |
| `abs(number)` | Модуль числа |
| `min(...)`, `max(...)` | Минимум/максимум из аргументов или списка |
| `sum(list)` | Сумма чисел |
| `round(number, digits)` | Округление |
| `int(value)`, `float(value)` | Преобразование чисел |
| `str(value)` | Преобразование в строку |
| `bool(value)` | Преобразование в логическое значение |
| `clamp(value, low, high)` | Ограничить число диапазоном |
| `rand(low, high)` | Случайное число с плавающей точкой |
| `randi(low, high)` | Случайное целое |
| `sin(x)`, `cos(x)` | Синус и косинус |
| `sqrt(x)` | Квадратный корень |
| `atan2(y, x)` | Угол по координатам |
| `hypot(a, b)` | Длина гипотенузы |
| `PI`, `TAU` | Математические константы |

Методов строк, списков и словарей нет. Вместо `items.append(x)` используй
новый список, например `items = items + [x]`. Вместо `math.sin` — просто `sin`.
`str()` нельзя применять к объектам `me()` и `cursor()`; выводи их отдельные поля.

Также нет `enumerate`, `zip`, `sorted`, `any`, `all`, `map` и `filter` —
используй `range`, индексы и обычные циклы.

### 2.3. Что запрещено

Запрещены:

- импорты (`import`, `from ... import ...`) и любые модули;
- классы;
- лямбды;
- списковые, словарные и генераторные включения;
- генераторы, `yield`;
- множества (`set`) и литералы множеств;
- `try` / `except`;
- `with`;
- `raise`;
- `async` / `await`;
- `del`;
- `global` / `nonlocal`;
- `assert`;
- `match`;
- моржовый оператор `:=`;
- распаковка аргументов `*args` и `**kwargs`;
- аннотации типов;
- декораторы;
- имена и атрибуты, начинающиеся с `_`;
- изменение атрибутов объектов;
- доступ к файлам, сети, системе и внутренностям сервера;
- `eval`, `exec`, `open`, `getattr`, `setattr`, `globals`, `locals` и подобные функции.

Вместо `math` и `random` используются встроенные `sin`, `cos`, `rand`,
`randi` и другие функции из таблицы выше.

### 2.4. Ограничения функций и f-строк

У функций допустимы только обычные позиционные аргументы и значения по умолчанию:

```python
def damage_bonus(base, extra=0):
    return base + extra

log(damage_bonus(10, 2))
```

Нельзя использовать `*args`, `**kwargs`, keyword-only аргументы, аннотации
типов и рекурсию глубже 10 уровней. `return` допустим только внутри `def`,
а `break` и `continue` — только внутри цикла.

F-строки поддерживаются только простые:

```python
log(f"HP: {me().hp}, mana: {me().mana}")
```

Нельзя использовать формат-спецификаторы (`{hp:.1f}`), `!r` и вставлять в
f-строку целые объекты `me()` / `cursor()`.

## 3. Жёсткие лимиты

### 3.1. Лимиты кода и интерпретатора

| Параметр | Лимит |
| --- | ---: |
| Размер исходника | 12 000 символов |
| Узлов AST | 2 000 |
| Шагов интерпретатора | 6 000 |
| Итераций одного цикла | 300 |
| Итераций всех циклов | 1 000 |
| Глубина рекурсии | 10 |
| Элементов в списке/кортеже/словаре | 250 |
| Длина строки | 4 000 |
| Размер целого числа | 2 048 бит |
| Элементов `range()` | 1 000 |
| Строк `log()` за каст | 6, до 220 символов |
| Фраз `say()` за каст | 2, до 80 символов |

Пустой код не принимается. Слишком сложный код останавливается с ошибкой
«Заклинание оказалось слишком сложным».

### 3.2. Лимиты боя

| Параметр | Значение |
| --- | ---: |
| Максимум HP | 100 |
| Максимум маны | 100 |
| Действий за каст | 7 |
| Перезарядка каста | 0,72 с |
| Восстановление маны | 11,25 в секунду |
| Замедление от `frostbolt` | 2,4 с, скорость ×0,58 |
| Оглушение небесной карой | 0,5 с, блокирует движение, каст и перекат |
| Перекат `Shift` | 165 единиц, кулдаун 1,6 с, неуязвимость 0,22 с |
| Возрождение | 3 с |
| Радиус мага | 18 |
| Размер арены | 1900 × 1100 |
| Отступ от края арены | 46 |

Мана **не восстанавливается внутри заклинания**. Если на старте каста у тебя
100 маны, а комбо стоит 95, всё сработает. Если у тебя 80 — последняя руна
не сработает, и код остановится на ошибке.

Лимит действий проверяется при каждом вызове боевой руны. Если попытаться
сделать восьмое действие, первые семь останутся выполненными, а заклинание
завершится ошибкой.

## 4. Состояние мира

### 4.1. `me()`

Возвращает read-only представление своего мага:

| Поле | Значение |
| --- | --- |
| `.name` | Имя |
| `.x`, `.y` | Координаты |
| `.hp`, `.max_hp` | Здоровье и максимум |
| `.mana`, `.max_mana` | Мана и максимум |
| `.shield` | Текущий щит |
| `.aim` | Текущий угол прицела |

В `me()` **нет** полей перезарядки щита и лечения. Поэтому нельзя заранее
проверить, готов ли `shield()` или `heal()`; при кулдауне вызов завершит
заклинание ошибкой.

### 4.2. Прицел

| Вызов | Что возвращает |
| --- | --- |
| `aim()` | Угол направления на курсор или джойстик |
| `cursor()` | Точку под курсором или `None` |
| `direction(x, y)` | Угол от своего мага к точке |
| `distance(x1, y1, x2, y2)` | Расстояние между точками |
| `ARENA_W`, `ARENA_H` | Размеры арены |

Поля точки курсора: `.x`, `.y`, `.dist`.

Автонаводки нет: сервер не выбирает врагов и не подсказывает направление.
`aim()` всегда направлен туда, куда смотрит курсор или джойстик. `cursor()`
нужен для заклинаний, которые ставятся в точку.

Всегда проверяй `cursor()` на `None`, если каст может произойти без мыши:

```python
point = cursor()
if point:
    log(point.x, point.y, point.dist)
```

## 5. Боевые руны

### 5.1. Стоимость и ограничения

| Руна | Мана | Можно за каст |
| --- | ---: | --- |
| `fireball` | 11 | сколько угодно раз |
| `frostbolt` | 9 | сколько угодно раз |
| `dash` | 10 | один раз |
| `blink` | 17 | один раз |
| `shield` | 17 | по перезарядке |
| `heal` | 24 | по перезарядке |
| `nova` | 21 | один раз |
| `ward` | 15 | один раз |
| `spark_volley` | 25 | один раз |
| `beam` | 50 | один раз |
| `emp` | 36 | один раз |
| `chain_lightning` | 34 | один раз |
| `lightning_strike` | 32 | один раз |
| `meteor` | 38 | один раз |
| `siphon` | 28 | один раз |
| `poison_cloud` | 30 | один раз |

`log()` и `say()` не тратят действия и ману, но имеют собственные лимиты:
6 строк и 2 фразы за каст. Перекат на `Shift` тоже не тратит ману и действия,
но в таблице рун его нет: это отдельная способность.

### 5.2. Снаряды

#### `fireball(angle, speed=1.0)`

- Стоимость: 11 маны.
- Урон: 16.
- `speed`: от 0.6 до 1.5; больше скорость — быстрее снаряд.
- Можно использовать несколько раз за каст.
- Снаряд блокируется препятствиями.

#### `frostbolt(angle)`

- Стоимость: 9 маны.
- Урон: 10.
- Замедляет цель на 2,4 секунды: скорость движения ×0,58.
- Можно использовать несколько раз за каст.
- Снаряд блокируется препятствиями.

#### `spark_volley(angle, count=8, spread=1.1)`

- Стоимость: 25 маны.
- Урон: по 5 за искру.
- `count`: от 1 до 8.
- `spread`: от 0.2 до 1.6 радиана.
- Один раз за каст.
- Искры блокируются препятствиями.
- Маленький `spread` собирает искры в плотный пучок; большой — в широкий веер.

### 5.3. Луч

#### `beam(angle, length=780, width=96)`

- Стоимость: 50 маны.
- Урон: 34 всем врагам в полосе.
- `length`: от 300 до 1000.
- `width`: от 40 до 140.
- Один раз за каст.
- Луч **пробивает препятствия** и не требует прямой видимости.
- Широкий луч проще попасть по движущейся цели.

### 5.4. Перемещение

#### `dash(angle, dist=170)`

- Стоимость: 10 маны.
- Дальность: от 60 до 260.
- Один раз за каст.
- Не проходит сквозь препятствия и край арены.
- Если свободного пути меньше 40 единиц, будет ошибка «Путь рывка перекрыт».
- Может переместить на меньшее расстояние, чем запрошено, если путь обрывается.

#### `blink(x, y)`

- Стоимость: 17 маны.
- Один раз за каст.
- Переносит в свободную точку без требования свободного пути.
- Нельзя перенестись в препятствие или за край арены.

#### Перекат (`Shift`, не руна)

- Бесплатно: не тратит ману и не занимает действие в заклинании.
- Перемещает до 165 единиц в направлении движения.
- Если клавиши движения не нажаты, направление берётся из прицела.
- Кулдаун: 1,6 секунды. Неуязвимость: 0,22 секунды.
- Перекат проходит сквозь других магов, но не сквозь препятствия и не за край арены.
- Если свободного пути меньше 40 единиц, перекат не срабатывает и кулдаун не начинается.
- Недоступен мёртвому магу и не имеет отношения к платной руне `dash()`.
- Из кода заклинания перекат вызвать нельзя: это только управление игрока.

Перекат удобно использовать, чтобы уйти из-под метеорита, выйти из ядовитого
облака или сменить позицию до цепной молнии. Кратковременная неуязвимость также
позволяет не получить урон от тика облака или взрыва, если момент выбран точно.
Цепная молния бьёт мгновенно, поэтому перекат после её каста уже не поможет:
уходить из линии нужно заранее.

### 5.5. Защита и лечение

#### `shield()`

- Стоимость: 17 маны.
- Даёт 38 единиц щита на 4,2 секунды.
- Перезарядка: 3 секунды.
- Нельзя вызвать, если щит уже активен.
- Если щит на перезарядке, вызов завершит заклинание ошибкой.
- Щит поглощает урон до здоровья.

#### `heal()`

- Стоимость: 24 маны.
- Лечит до 30 HP, но не выше 100.
- Перезарядка: 4,5 секунды.
- Нельзя вызвать при полном здоровье.
- Если лечение на перезарядке, вызов завершит заклинание ошибкой.

### 5.6. Взрыв и мина

#### `nova(radius=150)`

- Стоимость: 21 маны.
- Урон: 15.
- Отбрасывает врагов на 42 единицы.
- `radius`: от 80 до 220.
- Один раз за каст.
- Работает вокруг твоего мага и не требует прямой видимости.

#### `ward(x, y)`

- Стоимость: 15 маны.
- Урон при срабатывании: 22.
- Радиус срабатывания: 74.
- Радиус взрыва: 118.
- Отбрасывание: 55.
- Взводится через 0,7 секунды, живёт 14 секунд.
- Ставится не дальше 480 единиц от мага.
- Место должно быть свободным.
- Один раз за каст.
- У одного игрока может быть не больше двух активных мин.

Если не передать координаты, мина ставится под своего мага:

```python
ward()
```

### 5.7. E.M.P.

#### `emp(x, y)`

- Стоимость: 36 маны.
- Радиус: 190.
- Дальность установки: 560.
- Через 1,0 секунды E.M.P. притягивает врагов к центру до 160 единиц.
- Через 1,5 секунды сфера взрывается: сжигает до 35 маны у каждого врага в
  радиусе и наносит 1 урон за каждую сожжённую единицу.
- Притяжение и взрыв — две отдельные фазы. Сначала врагов стягивает к центру,
  и только потом наносится урон.
- Один раз за каст.
- Точка должна быть внутри арены.
- Если у врага нет маны, при взрыве он получает 0 урона, но всё равно был
  притянут в первой фазе.
- После притяжения у цели остаётся 0,5 секунды, чтобы покинуть радиус;
  замедление `frostbolt` помогает удержать её внутри.
- Неуязвимая цель не притягивается и не получает урон.

### 5.8. Цепная молния

#### `chain_lightning(angle, targets=3)`

- Стоимость: 34 маны.
- Один раз за каст.
- `targets`: от 1 до 3; по умолчанию 3.
- Первая цель ищется в направлении `angle` не дальше 680 единиц и не дальше
  90 единиц вбок от линии. Выбирается ближайшая подходящая цель.
- Первая цель получает 30 урона, вторая — 24, третья — 18.
- Следующая цель выбирается как ближайший враг не дальше 300 единиц от
  предыдущей. Цепь не возвращается к уже выбранным целям и не бьёт своего мага.
- Молния игнорирует препятствия и не требует прямой видимости.
- Если в направлении нет подходящей цели, заклинание завершается ошибкой
  «В направлении нет цели для цепной молнии», и мана не тратится. Перезарядка
  гримуара при этом всё равно начинается.
- Попадание в цель под щитом расходует щит, но цепь всё равно перескакивает
  дальше; урон следующей цели считается отдельно.
- Удобна против группы, но требует, чтобы враги стояли примерно по линии.

```python
chain_lightning(aim(), 3)
```

Молния летит по направлению прицела. Если в полосе окажется враг, цепь начнётся
с него; если нет — будет ошибка. Наводиться нужно вручную.

### 5.9. Метеорит

#### `meteor(x, y, radius=120)`

- Стоимость: 38 маны.
- Один раз за каст.
- Точка установки: не дальше 620 единиц от мага и внутри арены.
- `radius`: от 80 до 160; по умолчанию 120. Это радиус взрыва каждого
  метеора.
- В точку падают **три метеора**: основной камень и два меньших рядом.
- Все три падают через 1,15 секунды.
- Каждый метеор наносит 14 урона каждому врагу в своём радиусе. Если все три
  накрыли цель, суммарный урон — 42, как у прежнего одиночного метеорита.
- Отбрасывает только основной метеор: на 30 единиц от своего центра.
- Работает по площади, не требует прямой видимости и игнорирует препятствия.
- Точка не обязана быть свободной: метеориты можно призвать на препятствие или
  пустое место.
- Враги видят предупреждающие круги и могут выйти из радиуса или перекатиться
  на `Shift`. Неуязвимость переката защищает от попадания.
- Урон получают все враги в каждом радиусе, включая тех, кто стоит за
  укрытием. Камни визуально летят по диагонали с огненным шлейфом.

```python
point = cursor()

if point:
    meteor(point.x, point.y, 140)
else:
    meteor(me().x + cos(aim()) * 360, me().y + sin(aim()) * 360)
```

### 5.10. Небесная кара

#### `lightning_strike(angle)`

- Стоимость: 32 маны.
- Один раз за каст.
- `angle` — направление прицела. Передавай `aim()`, а не объект цели.
- Молния бьёт первого врага в узкой полосе по направлению прицела.
- Удар мгновенный, без снаряда и задержки.
- Урон: 28.
- Дальность: 760.
- Оглушает цель на 0,5 секунды. Оглушённый маг не может двигаться, колдовать и
  перекатываться; урон по нему проходит как обычно.
- Молния игнорирует препятствия и не требует прямой видимости.
- Щит поглощает урон, но не отменяет оглушение. Неуязвимость от переката
  отменяет и урон, и оглушение.
- Полоса узкая, поэтому промах возможен. Если в направлении нет врага,
  заклинание завершается ошибкой «В направлении нет цели для небесной кары»,
  и мана не тратится. Перезарядка гримуара при этом всё равно начинается.

```python
lightning_strike(aim())
```

### 5.11. Похищение жизни

#### `siphon(angle, length=380, width=64)`

- Стоимость: 28 маны.
- Один раз за каст.
- `length`: от 160 до 520; по умолчанию 380.
- `width`: от 36 до 110; по умолчанию 64.
- Луч наносит 18 урона каждому врагу в полосе.
- Лечит мага на 60% **фактически потерянного** здоровья целей, но не больше
  18 HP за каст.
- Щит и неуязвимость уменьшают фактический урон, поэтому лечение от них
  уменьшается вплоть до нуля.
- Луч игнорирует препятствия и не требует прямой видимости.
- Если луч никого не задел, мана всё равно тратится, а лечение равно 0.
- Лечение не может поднять здоровье выше 100.

```python
siphon(aim())
```

### 5.12. Ядовитое облако

#### `poison_cloud(x, y, radius=110)`

- Стоимость: 30 маны.
- Один раз за каст.
- Точка установки: не дальше 520 единиц от мага и внутри арены.
- `radius`: от 70 до 150; по умолчанию 110.
- Облако живёт 4,2 секунды.
- Первый тик — через 0,75 секунды, затем каждые 0,75 секунды.
- Каждый тик наносит 6 урона всем врагам внутри радиуса. Если стоять в облаке
  всё время, срабатывает 5 тиков — до 30 урона.
- Облако не замедляет, не требует прямой видимости и игнорирует препятствия.
- Щит поглощает каждый тик отдельно; перекат с неуязвимостью может пропустить
  один тик.
- Облако остаётся на месте, даже если маг ушёл. Оно исчезает через 4,2 секунды
  или при выходе владельца с арены.

```python
point = cursor()

if point:
    poison_cloud(point.x, point.y, 140)
else:
    poison_cloud(me().x + cos(aim()) * 320, me().y + sin(aim()) * 320)
```

## 6. Механика боя

- Щит поглощает урон любого типа, включая урон E.M.P., метеорита и тиков
  ядовитого облака, до здоровья.
- Снаряды `fireball`, `frostbolt` и `spark_volley` блокируются препятствиями.
- `beam`, `siphon`, `chain_lightning`, `lightning_strike`, `meteor` и
  `poison_cloud` препятствия игнорируют и не требуют прямой видимости.
- `nova`, `ward`, `emp`, `meteor` и `poison_cloud` работают по радиусу.
- `chain_lightning` сначала ищет цель в узкой полосе, а затем перескакивает
  между врагами; укрытие не разрывает цепь.
- `lightning_strike` бьёт первого врага в узкой полосе по направлению прицела;
  промах возможен. Оглушение на 0,5 секунды блокирует движение, каст и перекат,
  но не мешает получать урон.
- E.M.P. сначала притягивает врагов в радиусе 190, а через 0,5 секунды после
  притяжения взрывается и сжигает ману.
- `siphon` лечит только от фактической потери HP. Урон, поглощённый щитом или
  отменённый неуязвимостью, не превращается в лечение.
- `meteor` роняет три камня через 1,15 секунды; за это время цель может выйти
  из радиуса или использовать перекат. Урон каждого камня — 14, суммарно до 42.
- `poison_cloud` наносит урон тиками; каждый тик проверяет щит и неуязвимость
  отдельно.
- `dash`, `blink` и перекат не позволяют оказаться внутри препятствия или за
  границей арены.
- Перекат на `Shift` — бесплатное движение с кулдауном 1,6 секунды и
  неуязвимостью 0,22 секунды. Он не тратит ману и не входит в лимит действий.
- Радиус мага — 18 единиц.
- Арена — 1900 × 1100, отступ от края — 46.
- Скорость движения — 238 единиц в секунду.
- После 7 секунд без получения урона здоровье медленно восстанавливается.
- После смерти маг возрождается через 3 секунды с полными HP и маной.
- Одновременно в воздухе может быть не более 120 снарядов; очень старые
  снаряды удаляются.

## 7. Ошибки и их последствия

Ошибка заклинания:

- не отнимает здоровье;
- **не возвращает уже потраченную ману**;
- всё равно запускает перезарядку гримуара на 0,72 с;
- останавливает выполнение кода на этой строке;
- показывает номер строки в интерфейсе.

Код до ошибки уже сработал: например, если после `fireball` не хватило маны
на `beam`, фаербол уже полетел, а `beam` не создался.

Частые ошибки:

| Сообщение | Причина |
| --- | --- |
| `Не хватает маны` | Следующая руна дороже остатка маны |
| `Слишком много действий` | Попытка сделать восьмое действие |
| `Щит уже активен` | `shield()` при ненулевом щите |
| `Щит восстанавливается` | `shield()` на кулдауне |
| `Здоровье уже полное` | `heal()` при полном HP |
| `Исцеление будет готово через...` | `heal()` на кулдауне |
| `E.M.P. можно создать не дальше 560` | Точка вне радиуса |
| `E.M.P. нужно навести внутрь арены` | Точка за границей |
| `Руну можно поставить не дальше 480` | Точка вне радиуса |
| `Руна не помещается на это место` | Препятствие или край арены |
| `Путь рывка перекрыт` | `dash` не нашёл свободный путь |
| `В направлении нет цели для цепной молнии` | В полосе 680 × 180 (по 90 вбок) нет врага |
| `Количество целей должно быть от 1 до 3` | Неверный `targets` у `chain_lightning` |
| `В одном заклинании возможна только одна цепная молния` | Повторный `chain_lightning` за каст |
| `В направлении нет цели для небесной кары` | В узкой полосе по направлению прицела нет врага |
| `В одном заклинании возможна только одна небесная молния` | Повторный `lightning_strike` за каст |
| `Вы оглушены и не можете колдовать` | Попытка каста во время оглушения |
| `Метеорит можно призвать не дальше 620` | Точка вне радиуса `meteor` |
| `Метеорит нужно навести внутрь арены` | Точка за границей |
| `Облако можно создать не дальше 520` | Точка вне радиуса `poison_cloud` |
| `Облако нужно навести внутрь арены` | Точка за границей |
| `В одном заклинании возможен только один метеорит` | Повторный `meteor` за каст |
| `В одном заклинании возможно только одно похищение жизни` | Повторный `siphon` за каст |
| `В одном заклинании возможно только одно ядовитое облако` | Повторный `poison_cloud` за каст |
| `Неизвестное имя` | Опечатка или недоступная функция |
| `Импорт запрещён` | Попытка импортировать модуль |
| `Конструкция ... недоступна` | Неподдерживаемый синтаксис |
| `Гримуар перезаряжается` | Каст раньше 0,72 с |
| `Маг мёртв` | Маг ждёт возрождения |

`try/except` в языке нет, поэтому проверяй условия заранее:

```python
if me().hp < 50 and me().shield < 1:
    shield()
```

Но помни: проверить кулдаун щита или лечения через API нельзя. Если руна
на перезарядке, её вызов всё равно завершит заклинание ошибкой.

Ошибки переката не относятся к заклинанию и не тратят ману:
`Перекат восстанавливается: ... с.` означает, что `Shift` ещё на кулдауне;
`Перекат заблокирован препятствием.` — что в выбранном направлении нет
достаточно свободного пути; `Оглушение: перекат недоступен.` — что маг под
небесной карой; `Дождитесь возрождения.` — что маг мёртв.
Показать эти сообщения можно только в интерфейсе, из кода их не поймать.

## 8. Как проектировать заклинание

1. **Определи роль:** burst, защита, контроль, зонирование, отложенный урон,
   лечение или добивание.
2. **Посчитай бюджет:** 7 действий и 100 маны. Дорогие руны могут не влезть
   в одно комбо.
3. **Проверь состояние:** HP, ману, щит, дистанцию и курсор.
4. **Сделай ветки:** близко/далеко, полный HP/ранен, есть щит/нет щита.
5. **Защити рискованные вызовы:** `shield()`, `heal()`, `emp()`, `chain_lightning()`,
   `lightning_strike()`, `meteor()`, `poison_cloud()` и `cursor()`.
6. **Оставь ману на следующий каст:** после каста всё ещё действует перезарядка
   и нужно успеть нанести следующий удар.
7. **Проверь прицел:** снаряды и лучи могут промахнуться. У `beam`, `siphon`,
   `chain_lightning` и `lightning_strike` своя геометрия, а `meteor` и
   `poison_cloud` имеют отдельные радиусы установки.

### Пример: ручной прицел и защита

```python
# Сначала щит, если он не активен и здоровья мало.
if me().hp < 50 and me().shield < 1:
    shield()

# Плотный веер искр по курсору.
if me().mana >= 25:
    spark_volley(aim(), 8, 0.2)

fireball(aim(), 1.5)
```

`aim()` смотрит на курсор. `spark_volley` стоит 25, фаербол — 11; вместе 36
маны и 2–3 действия.

### Пример: рунная засада

```python
point = cursor()

if point:
    ward(point.x, point.y)
else:
    ward()

frostbolt(aim())
```

Руна ставится в точку курсора. Если каст идёт без мыши, `ward()` поставит её
под ноги. Снаряд после этого летит строго по прицелу.

### Пример: максимальный burst

```python
# 7 действий, 91 мана: до 136 урона при попадании всех снарядов.
spark_volley(aim(), 8, 0.2)

fireball(aim(), 1.5)
fireball(aim(), 1.5)
fireball(aim(), 1.5)
fireball(aim(), 1.5)
fireball(aim(), 1.5)
fireball(aim(), 1.5)
```

### Пример: E.M.P. с замедлением

```python
point = cursor()

if point and point.dist <= 540:
    emp(point.x, point.y)
else:
    emp(me().x + cos(aim()) * 360, me().y + sin(aim()) * 360)

frostbolt(aim())
```

E.M.P. сначала притянет цель через 1,0 секунды, а взорвётся через 1,5 секунды.
`frostbolt` замедляет цель, чтобы ей было сложнее выйти из радиуса после
притяжения. Если навести E.M.P. дальше 560, будет ошибка.

### Пример: цепная молния по группе

```python
chain_lightning(aim(), 3)
fireball(aim())
```

Цепная молния стоит 34 маны, фаербол — 11. Если враги стоят цепочкой не дальше
300 единиц друг от друга, молния может задеть до трёх целей. Наводи первую цель
самостоятельно: если в полосе по прицелу никого нет, будет ошибка.

### Пример: небесная кара

```python
lightning_strike(aim())
fireball(aim())
```

`lightning_strike` стоит 32 маны и бьёт мгновенно. Если прицел совпал с врагом,
оглушение на 0,5 секунды не даст ему уйти с линии, и следующий снаряд попадёт
легче. Полоса узкая, поэтому промах возможен.

### Пример: зона контроля

```python
point = cursor()

if point and point.dist <= 500:
    meteor(point.x, point.y, 140)
    poison_cloud(point.x, point.y, 130)
else:
    frostbolt(aim())
```

Метеорит и облако вместе стоят 68 маны и занимают 2 действия. Метеорит
срабатывает через 1,15 секунды, облако живёт 4,2 секунды и тикает каждые
0,75 секунды. Такое комбо хорошо накрывает узкий проход, но враг может выйти
из зоны или перекатиться. `point.dist` проверяется заранее, потому что
`meteor` и `poison_cloud` не принимают точку дальше 620 и 520 соответственно.

### Пример: похищение жизни

```python
siphon(aim())
frostbolt(aim())
```

`siphon` стоит 28 маны и лечит до 18 HP, но только от реально потерянного
здоровья. Если у цели активен щит, лечение будет меньше. Луч проходит сквозь
укрытия, поэтому им можно достать врага за колонной, если направить прицел
точно на него.

### Отладка

```python
log("hp", me().hp, "mana", me().mana)
log("cursor", cursor())
```

`log()` и `print()` выводят строки только тебе, в панель «Печать». До 6 строк
за каст. Если заклинание не работает, сначала посмотри номер строки и текст
ошибки в интерфейсе.

## 9. Частые ошибки новичков

- **Пытаться ждать.** `while` не делает паузу; время внутри каста не идёт.
- **Писать «программу на будущее».** Код запускается один раз, а не каждый тик.
- **Тратить всю ману на атаку.** После каста нужна мана на защиту или добивание.
- **Забывать про 7 действий.** Восьмая руна не сработает.
- **Вызывать `shield()` без проверки.** При активном щите — ошибка.
- **Вызывать `heal()` при полном HP.** Это тоже ошибка.
- **Считать, что `shield()`/`heal()` можно проверить по кулдауну.** В API
  нет полей перезарядки.
- **Рассчитывать на автонаводку.** Её нет: каждую атаку нужно направлять вручную.
- **Забывать про `cursor() is None`.** При касте без мыши точка может быть `None`.
- **Ставить E.M.P. дальше 560.** Будет ошибка, и код после него не выполнится.
- **Считать, что метеорит падает сразу.** Он срабатывает через 1,15 секунды;
  цель может уйти из круга.
- **Стоять в ядовитом облаке.** Оно тикает каждые 0,75 секунды, и щит тратится
  на каждый тик отдельно.
- **Ждать лечения от `siphon` по щиту.** Лечение считается только от реально
  потерянного HP.
- **Пускать цепную молнию без цели.** Если в полосе 680 × 180 никого нет, каст
  завершится ошибкой. Наводись прицелом на врага.
- **Целиться небесной карой мимо.** Она бьёт только первого врага в узкой полосе
  по направлению прицела; промах завершится ошибкой.
- **Путать `Shift` и `dash()`.** Перекат бесплатный, не тратит ману и не
  занимает действие; `dash()` — платная руна внутри кода.
- **Использовать `import math`.** Нужны встроенные `sin`, `cos`, `sqrt`.
- **Пытаться изменить `me().hp`.** Состояние доступно только для чтения.
